EXTENSION STUDIO

Build for FireFox GX

Create a folder with manifest.json and your scripts/styles, import it for testing, then package it as .fgxe. FireFox GX runs compatible content scripts; Chrome APIs and Firefox APIs may need adaptation.

Starter manifest.jsonSave as manifest.json in your extension folder
{
  "manifest_version": 3,
  "name": "My GX Extension",
  "version": "1.0.0",
  "description": "What it does",
  "permissions": [],
  "content_scripts": [{
    "matches": ["https://example.com/*"],
    "js": ["content.js"],
    "run_at": "document_idle"
  }]
}

Test imports require explicit permission review. The package scanner flags dynamic code and broad privileges. It is a basic safety check, not a guarantee that code is harmless.
